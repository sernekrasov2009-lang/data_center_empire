# Uptime Empire

Экономический симулятор админа ЦОД для ПК (Electron + TypeScript + React).
Главные документы: **GAME.md** (правила и дорожная карта) и **DESIGN.md** (детальный дизайн).

## Запуск

```bash
npm install
npm run dev      # окно Electron + Vite с HMR
npm run build    # типы, интерфейс в dist/, main-процесс в dist-electron/
npm test         # Vitest
npm start        # собрать и запустить как приложение
```

Требуется Node.js LTS (проверено на 24.x) и npm.

## Управление (этап 2)

Все привязки переназначаются в настройках («Управление»), по две на действие.

| Клавиши | Действие |
|---|---|
| Пробел | пауза |
| 1 / 2 / 3 / 4 | скорость ×1 / ×5 / ×20 / ×60 |
| Ctrl+S / Ctrl+L | быстрое сохранение / быстрая загрузка |
| Esc | меню паузы, закрытие диалога |
| F3 | оверлей производительности |
| F11 | полный экран (обрабатывает main-процесс) |

## Файлы

- `settings.json` и `saves/` — в папке `userData` (`%APPDATA%\Uptime Empire` на Windows).
- Сейв: gzip-файл слота + `.meta.json` для списка, три бэкапа `.bak1..3`.
- Настройки и сейвы можно экспортировать и импортировать из диалога слотов.

## Экономика (этап 2)

- Старт: домашняя локация, старый ПК на 100 Вт, тариф «дом» $0,12/кВт·ч, PUE 1,8, интернет 100 Мбит/с за $20/мес, аренда $0.
- Электричество копится каждый игровой час. В конце месяца списываются накопленное электричество, интернет и аренда; в отчёте видны итог и остаток.
- Дашборд показывает счёт текущего месяца, расшифровку, прогноз на три месяца и последние шесть счетов.
- Тариф на электричество меняется раз в год в пределах ±20% через seeded RNG; одинаковый seed даёт одинаковую историю цен.
- Банкротство: на обычной и сложной сложности баланс ниже −$2000 завершает игру, на спокойной остаются предупреждения, в песочнице проверка отключена.

## Железо (этап 3)

- Вкладка «Сборка»: слоты под ЦП, плату, ОЗУ, диски, БП, корпус и сетевую карту; совместимость (сокет, тип ОЗУ, форм-фактор, запас БП 1,2×) проверяется сразу, сборка занимает до 2 часов.
- Вкладка «Магазин»: новые детали с месячным множителем цен 0,9–1,1 и б/у лоты со скидкой 30–60%, которые обновляются раз в неделю.
- Доставка: новые 1–3 дня, б/у 1–5 дней; бесплатно от $200, иначе $10. Заказ можно отменить в первые 12 часов, вернуть — в течение 3 дней с комиссией 10%.
- «Склад»: остатки запчастей, стоимость, список заказов и состояние ремонта. Отказы проверяются раз в сутки; ремонт — 48 часов или 6 часов при наличии такой же запчасти.
- Потребление всех готовых сборок идёт в счёт за электричество; стартовый домашний ПК — 100 Вт.

## Локация (этап 4)

- Экран «Локация и стойки»: два слота в домашней комнате. Сервер выбирается в слоте выпадающим списком, снятие со слота обесточивает его — электричество и шум считаются только по размещённым и включённым серверам.
- Питание: автомат на 1,5 кВт. Перегруз дольше часа выбивает пробки (серверы и охлаждение обесточены), сброс бесплатный, но перегруз вернётся. Счёт за электричество — ИТ-нагрузка × PUE 1,8 плюс потребление самого охлаждения.
- Температура: `T_room = T_outside + P_heat / C`. Сезонная кривая по месяцам и суточный ход; выше 35 °C отказы чаще, выше 45 °C троттлинг, выше 55 °C аварийное отключение с ручным перезапуском после остывания.
- Охлаждение: открытое окно (бесплатно), вентилятор ($30), сплит-кондиционер ($650, 300 Вт) и прецизионный CRAC ($5000). Купленный вариант переключается бесплатно.
- Шум и соседи: ночью (22:00–08:00) лимит 30 дБ. Раздражение растёт за каждый дБ сверх лимита: при 12% — жалоба, при 24% — штраф $50, при 48% — принудительное отключение. Шумоизоляция за $280 снижает шум на 8 дБ.
- Интернет: 100 Мбит/с за $20/мес и 300 Мбит/с за $35/мес, тариф меняется в любой момент и сразу виден в прогнозе счёта. Аренда комнаты $0.

## Структура

```
electron/        main-процесс и preload (окно, IPC, логи)
src/sim/         чистая логика: RNG, календарь, тики, экономика, железо (без React и DOM)
src/state/       Zustand-хранилище, настройки, горячие клавиши, игровой цикл
src/ui/          экраны, диалоги, компоненты и стили
src/platform/    доступ к системе через мост window.uptime
src/data/        числа баланса (balance.json, difficulties.json, economy.json, components.json, location.json) и валидация
src/save/        формат сохранения, миграции, метаданные слотов
src/i18n/        ru.json, en.json
tests/           Vitest
tools/           dev-скрипт, позже balance-sim
```

## Правила

- Все числа баланса — в `src/data/*.json`, интерфейсные строки — только через i18n.
- `src/sim/` не импортирует React/DOM/Electron.
- Случайность только через seeded RNG, `Math.random` запрещён.
- Файловая система — только через `preload` и каналы `save:*`, `settings:*`, `log:*`.
- Один этап за раз, коммит `stage N: описание`, обновление чек-листа и CHANGELOG.md.
