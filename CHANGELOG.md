# Changelog

Все заметные изменения проекта. Формат — по этапам дорожной карты (GAME.md, разд. 7).

## 0.1.0 — этап 0: каркас

- Electron + Vite + TypeScript (strict) + React + Zustand + Vitest.
- `electron/main.ts`: окно 1440×900 (минимум 1280×720), один экземпляр, F11, запрет переходов и новых окон, ротация логов `userData/logs/app.log` (5 файлов по 1 МБ).
- `electron/preload.ts` + `src/platform/`: единственный мост `window.uptime` (contextIsolation включён, nodeIntegration выключен, sandbox включён), каналы `log:*`.
- `src/sim/`: чистое ядро без React и DOM — seeded RNG (mulberry32), календарь (тик = 1 час, сутки = 24, месяц = 30), `advanceTicks`, скорости и пауза.
- `src/data/balance.json`: темп времени, стартовые условия, лимиты, предохранители; валидация данных и тест.
- Игровой цикл на `requestAnimationFrame` с аккумулятором времени, скорости ×1/×5/×20/×60, пауза.
- i18n ru/en без сторонних библиотек, переключение языка в верхней панели, выбор запоминается.
- Интерфейс: тёмная неоновая тема, верхняя панель (деньги, дата, скорости), навигация с заглушками, дашборд, лента событий, нижняя строка подсказок.
- Оверлей производительности F3: FPS, время шага симуляции, тики, seed, память, версии.
- Горячие клавиши: Пробел, 1–4, F3 (F11 — в main-процессе).
- Тесты: баланс, RNG, календарь, игровой цикл.
